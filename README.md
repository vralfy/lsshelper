# LSS Helper

1. Install [Tampermonkey](https://www.tampermonkey.net)
2. Enable developer mode in browser (if needed)
3. Click [here](https://github.com/vralfy/lsshelper/raw/master/lsshelper.user.js) to install

## AddOns

1. [Install Distribution Helper](https://github.com/vralfy/lsshelper/raw/master/lsshelper.distribution.user.js)
   This plugin shows distribution of vehicles over the map. Find "blind spots" where specific vehicles are needed or vehicles have to maintain huge territories.
2. [Install EasterEgg Helper](https://github.com/vralfy/lsshelper/raw/master/lsshelper.easteregg.user.js)
   This plugin automaticaly claims easter eggs.
3. [Install Direct Send Fix](https://github.com/vralfy/lsshelper/raw/master/lsshelper.directsend.user.js)
   This plugin shows a button within mission description to send all double assigned vehicles to this mission.
   Sometimes LSS Helper assigns a vehicle twice causing the mission to stay in attended mode.
